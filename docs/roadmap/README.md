## How This Is Maintained

- Each roadmap document is owned by the lead for that scope.
- Updates happen via PR; no direct pushes to `main`.
- Outdated roadmaps are archived to `reference/archive/`, not deleted.
- Root-level `ROADMAP.md` is a thin redirect to [current.md](current.md).
